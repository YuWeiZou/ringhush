> English | [中文](./维护指南.md)

> Applies to **Release 2.6.1a19** (2026-10-24).

## 1. Three Main Flows

```
Browser public/app.js
   │  WebSocket /ws (JSON)
   ▼
server/index.js ──► server/rooms.js ──► src/engine/game.js
   │                                      │
   │ static files                         ├─ actions.js / map.js / rng.js
   │ /  → public/                         ├─ shared/ring.js (shared by frontend and backend)
   │ /shared/ → shared/                   └─ aiRuntime.js ──► ai/models/*.js
   │                                                          └─ ai/lib/*.js
   └─ match end: gameover + full replay record → browser history.js (IndexedDB)
```

- **Trust only the server for rules**: the `view` the client receives is already filtered per player; do not move rule decisions to the frontend.
- **AI gets only its own perspective**: `buildAIContext()` deliberately does not provide other players' positions.
- **Replay is god view**: complete attack outcomes and all positions go only into `getReplayRecord()`, never into a player's `view`.

## 5. Constraints That Must Not Be Broken

1. **Information isolation**: a non-spectator's `getView()` returns only their own `position`; the `players` in `buildAIContext()` contain no positions. Any full-position broadcast for “debugging convenience” is forbidden.
2. **Attack outcomes are not sent back**: players/AI know only that they fired and the target arc length; hit/empty shot/blocked/mutual attack outcomes go only into the replay.
3. **Fixed resolution order**: Hide → Observe → Slip → Attack → Death; Hide on a Plain is an empty action, only Hide on a Pillar grants invisibility.
4. **Phase machine**: `lobby → selecting → resolved → selecting / over`; no new round starts after `over`.
5. **Timeouts and AI**: a human who times out is treated as Hide; AI and humans reason simultaneously; after all humans submit, wait for AI to finish before resolving.
6. **AI-only**: when no living humans remain, use `autoResolveAIOnly()` to run to the end; must not get stuck in `selecting`.
7. **`shared/ring.js` must be isomorphic**: both Node and the browser can import it directly; `window`, `fs`, `process` must not appear.
8. **The browser uses absolute-path imports**: `/board.js`, `/shared/ring.js`; the server maps `/shared/` to `shared/` and everything else to `public/`.
9. **Release packages exclude tests/training/tools**: see the §7 allowlist.
10. **Rule changes must touch both tests and the rulebook**: `test/engine.test.js` + `规则书.md` / `规则书.en.md` (or explicitly change only the implementation without changing the rules, and document that in the RELEASE notes).

## 7. Release Process (currently manual packaging)

### 7.1 In-Package Allowlist

**Full version** `黑暗森林-<版本>.zip`:

- Root: `.gitignore`, `README.md`, `README.en.md`, `RELEASE-<版本>.md`, `RELEASE-<版本>.en.md`, `AI-BRIDGE.md`, `AI-BRIDGE.en.md`, `OPL联机说明.md`, `OPL联机说明.en.md`, `游戏介绍.md`, `游戏介绍.en.md`, `玩法与策略说明.md`, `玩法与策略说明.en.md`, `规则书.md`, `规则书.en.md`
- Startup: `start.bat`, `run-hidden.vbs`, `open-browser.vbs`, `launcher.mjs`, `ai-bridge.mjs`, `start-ai-bridge.bat`, `install-ai-bridge.bat`
- Dependencies: `package.json`, `package-lock.json`, `node_modules/ws/**`
- Runtime: `runtime/node.exe`, `runtime/README.txt`
- Code: `server/**`, `src/engine/**`, `shared/**`, `public/**` (including `public/audio/**`)
- AI: `ai/models/**`, `ai/lib/**`, `ai/external/_template/model.json`, `ai/README.md`, `ai/README.en.md`, `ai/EXTERNAL-MODELS.md`, `ai/EXTERNAL-MODELS.en.md`, `ai/gpu.config.json`

**Lite version** `黑暗森林-<版本>-lite.zip`: the full version without `public/audio/**`; everything else is identical.

**Explicitly excluded from the package**:

`test/`, `tools/`, `ai/sim/`, `ai/train/`, `设计笔记.md`, `GPU-VS-AI2.md`, `TRAINING-ITERATION-1.md`, `screenshots/`, `dist/`, `release/`, `logs/`, `docs/`, `AGENTS.md`, `AGENTS.en.md`, and everything under `node_modules` except `ws`.

> Note: `docs/` and `AGENTS.md` / `AGENTS.en.md` are maintenance material and are not shipped with player packages; if you want players to see the maintenance guide, that requires a separate decision.

### 7.2 Packaging Steps

1. Run `npm run verify`;
2. Bump the version number per §8, write `RELEASE-<版本>.md`, and update `设计笔记.md`;
3. Create a temporary directory and copy according to the 7.1 allowlist (do not zip the entire repository directly; `dist/` is 1.4 GB and the training data is about 390 MB);
4. Use `Compress-Archive` to produce the full version; copy it once and delete `public/audio/` to produce the Lite version;
5. Generate a checksum file with SHA256, in the format “uppercase hash + two spaces + filename”:

```powershell
Get-FileHash 'dist\黑暗森林-<版本>.zip' -Algorithm SHA256 | ForEach-Object { "$($_.Hash)  $(Split-Path $_.Path -Leaf)" } | Set-Content 'dist\SHA256-黑暗森林-<版本>.txt'
```

6. Extract the zip into a clean directory, double-click `start.bat`, and confirm that `/api/health` and the page work.

### 7.3 Release Checks

- [ ] `npm run verify` all green
- [ ] The package contains no `test/`, `tools/`, `ai/sim/`, `ai/train/`, `docs/`
- [ ] Both the full version and the Lite version include the `*.en.md` English docs; the Lite version still has no audio
- [ ] The full version has `public/audio/playlists/long-night-dam/`; the Lite version does not
- [ ] `runtime/node.exe` exists and `node_modules/ws` is complete
- [ ] After extraction, double-clicking `start.bat` opens `http://localhost:3001`
- [ ] The versions in `RELEASE`, `README`, `package.json`, and the startup log match
- [ ] SHA256 files for both zips have been generated

## 10. Known Maintenance Debt / Next Steps

- **No git repository**: the current directory is not a git repo, so before changes you can only rely on `dist/` and backups. Recommend running `git init` later and adding `dist/`, `release/`, `runtime/`, `ai/train/data/`, `ai/train/checkpoints/*.pt`, `public/audio/**/*.wav` to `.gitignore`.
- **Manual release packaging**: there is no `build-release` script, and the allowlist is maintained by memory; it is easy to omit `node_modules/ws` or accidentally include training data. A `tools/build-release.mjs` could be added.
- **`public/app.js` is a monolith**: zone markers already lower the search cost, but it is still 2,800 lines; it could later be split by “settings/room/replay/match/actions”.
- **No automated UI tests**: only engine/AI unit tests; UI relies on `?auto=1` smoke tests and screenshots.
- **`release/` is an empty directory**: historical leftover; the actual artifacts are in `dist/`.
- **`dist/` is 1.4 GB**: old version zips accumulate; keeping the latest 2–3 versions is enough, and old packages can be archived outside the repository.
- **`logs/server-errors.log` is mostly port conflicts**: `start.bat` retries 3 times when 3001 is occupied; check the port first, and do not mistake it for a code crash.
- **Training data/weights are very large**: `ai/train/data/*.jsonl` is about 390 MB; do not open it in a normal editor, use `Get-Content -TotalCount` or a streaming script.

## 11. Troubleshooting Quick Reference

| Symptom | Check First |
|---|---|
| Exits immediately after startup; log shows `EADDRINUSE` | 3001 is occupied; switch to `PORT=3010` or kill the old process |
| Page opens but there is no AI | Whether `ai/models/` is empty; `aiModels` in `/api/health` |
| “Start Match” in the room is grayed out | Fewer than 2 players, an invalid AI model, or not the host |
| Cannot join an online game | Host firewall on 3001; the local port mapped by OPL; room-code case sensitivity |
| No replay record | Whether the match ended normally; whether browser site data was cleared; whether the player disconnected before the end |
| Bridge cannot connect | Whether 3210–3218 are occupied; whether `round_ack` is replied to; whether it listens only on `127.0.0.1` |
| AI is stuck and does not resolve | Check the server log `[ai]`; whether an AI model throws/times out; whether `prepareAIActions` completes |
| Page is stale after changes | Server `cache-control: no-cache`; hard-refresh the browser; confirm you changed `public/`, not the old package in `dist/` |

2. Read the zone's entry functions and adjacent tests first;
